Folders, menus and edit mode

Try it on the phone: press and hold an icon, a folder or a widget; hold an empty bit of wallpaper for edit mode; tap a folder. In edit mode drag an icon onto another to make a folder, tap a minus to remove one, pull a widget's round corner, and tap the brush (or Edit, with twist 8 off) for Customise. Esc leaves edit mode.

Where today's things went

  • Hold an icon: its menu appears beside it while you hold. Move your finger to pick it up instead.
  • Hold an empty spot: edit mode. It opened Customise before; Customise is now Edit › Customise.
  • Removing: tap the minus in edit mode, or Remove in the menu. It asks “Remove from Home Screen” or “Uninstall App”. Undo stays. The bin at the top of the screen goes.
  • Resizing: pull a widget's round corner in edit mode, or pick Small, Medium or Large at the top of its menu. Apps: Resize in their menu.
  • Renaming a folder: Rename in its menu, or open it in edit mode.
  • Kept as menu rows: an app's shortcuts and their +, Edit Name and Icon, App Info, Colour for folders and widgets, Stack Another Widget, Glass Behind It, Edit Widget (each widget's set-up), Unlock Layout.
  • Gone: Open (tap the icon instead), the “N apps” line and the hint inside folders, the Move arrows (drag instead; TalkBack keeps move actions).

Menus not shown on the phone. Another app's widget: the size row, Glass Behind It, Stack Another Widget, Edit Home Screen, Remove Widget. A stack: the size row, Edit “Clock”, Edit Stack, Edit Home Screen, Remove Stack.

The glass is the same in Light and Dark. On the phone it is Zenith's own Liquid Glass, which bends the real wallpaper at its edges; a web page can only blur it.
